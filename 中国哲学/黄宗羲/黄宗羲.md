# 黄宗羲（1610—1695）

## 一、人物与思想概述

黄宗羲，字太冲，号南雷，学者称梨洲先生，浙江余姚人。明清之际思想家、史学家，东林之后。其《明夷待访录》猛烈批判专制君权，提出「天下为主，君为客」「公其非是于学校」的启蒙政治构想；《明儒学案》《宋元学案》开创学术史之体例。其学兼综阳明心学与蕺山之慎独，主「心无本体，工夫所至即其本体」。

**核心命题：**
- **君客民主**：古者天下为主、君为客；今也君为主、天下为客。
- **君为大害**：为天下之大害者，君而已矣。
- **君臣共曳**：君与臣，共曳木之人也，非主仆。
- **学校议政**：必使治天下之具皆出于学校，天子之所非未必非。
- **心无本体**：心无本体，工夫所至即其本体。
- **盈天地皆心**：心遍在万物，构成世界（#self-other）。
- **工商皆本**：世儒以工商为末，误也。

**思想史位置：** 中国早期启蒙思想家，其政治论比肩卢梭之前驱；学术史著述体例之奠基者，心学殿军而转向实学。

## 三、对外界的认知（B类）

1. 古者以天下为主，君为客；凡君之所毕世而经营者，为天下也。——《明夷待访录·原君》
2. 今也以君为主，天下为客。——《明夷待访录·原君》
3. 然则为天下之大害者，君而已矣。——《明夷待访录·原君》
4. 缘夫天下之大，非一人之所能治，而分治之以群工。——《明夷待访录·原臣》
5. 君与臣，共曳木之人也。——《明夷待访录·原臣》
6. 天下之治乱，不在一姓之兴亡，而在万民之忧乐。——《明夷待访录·原臣》
7. 不以一己之利为利，而使天下受其利；不以一己之害为害，而使天下释其害。——《明夷待访录·原君》
8. 天子之所是未必是，天子之所非未必非。——《明夷待访录·学校》
9. 必使治天下之具皆出于学校。——《明夷待访录·学校》
10. 公其非是于学校。——《明夷待访录·学校》
11. 有明之无善治，自高皇帝罢丞相始也。——《明夷待访录·置相》
12. 宰相既罢，天子更无与为礼者矣。——《明夷待访录·置相》
13. 传贤之法，固可于郡县之中行之。——《明夷待访录·置相》 〔意译〕
14. 学校，所以养士也，而亦所以议政也。——《明夷待访录·学校》 〔意译〕
15. 治天下者，贵得人而已。——《明夷待访录》 〔意译〕
16. 法弊则改，政敝则更，贵在因时。——《明夷待访录》 〔意译〕
17. 天下之法，当为天下而立，非为一姓而立。——《明夷待访录·原法》 〔意译〕
18. 有治法而后有治人。——《明夷待访录·原法》
19. 三代以上之法，为天下也；后世之法，为一己也。——《明夷待访录·原法》 〔意译〕
20. 工商皆本，世儒以工商为末，妄也。——《明夷待访录·财计》 〔意译〕

24. 科举之弊，在乎徒事章句。——《明夷待访录·取士》 〔意译〕

## 五、出处与真伪说明

- **文本性质**：黄宗羲多自著论说与学术史案语。可逐字直录者（如《明夷待访录》诸条、《明儒学案·自序》二条）已尽量采原句；其案语、文集多有概括性论断，难以逐字成句者，据原意凝练并标 `〔意译〕`。
- **版本**：以《黄宗羲全集》（浙江古籍出版社）为底本；《明夷待访录》用中华书局点校本。
- **归类**：A2「盈天地皆心也」为心遍在万物之论，主客同构，依规范加 `#self-other`，归入 A 类另作统计。A1「心无本体，工夫所至即其本体」为其心性论纲领，入 A。
- **存疑**：第 B3、B34 等涉及「产业」「自利」之表述，为《原君》篇意旨之凝练，非必逐字原文，标 `〔意译〕`，未计入伪托。
