# 帕斯卡（1623—1662）

## 一、人物与思想概述

布莱兹·帕斯卡（Blaise Pascal）是数学家、物理学家，也是詹森主义最重要的护教思想家。《思想录》是他未及编订的护教手稿残片，以格言与片段的形式写就，密度极高、思想跳跃。全书围绕一个核心张力展开：人介于「无限大」与「无限小」之间，既因思想而伟大，又因必死、无知与败坏而悲惨；理性在此抵达边界，唯「心」能领会上帝。这种把人的尊严与卑微并置、以「赌注」与「芦苇」为象征的写法，使他成为信仰主义与存在主义的重要源头。

**核心命题：**
- **会思想的芦苇**：人的全部尊严在于思想。
- **两个无限**：人在伟大与渺小两个无限之间悬浮。
- **心有其理**：理性不认识心的理由。
- **消遣**：人用忙碌逃避面对自身的悲惨。
- **自我可恨**：以自我为中心是人与生俱来的病。
- **上帝在心里**：上帝由心感知，而非由理性证明。
- **信仰的赌注**：理性的天平在信仰一端倾斜。

**思想史位置：** 介于笛卡尔理性主义与蒙田怀疑主义之间；他以「不确定中的确定」影响帕斯卡尔主义、克尔凯郭尔与当代护教哲学，其人对理性的清醒限制预示了康德与的存在论转向。

## 五、出处与真伪说明

- **编号体系**：《思想录》为未定稿残片，通行编号有**拉夫马（Lafuma, L）本**与**布伦士维格（Brunschvicg, B）本**两种，二者编号不对应。本文件统一采用 **Lafuma 编号（L）**，并在正文以「L数字」标注。个别片段（未标注 L 号者）为编者归类于某主题群的残句，其精确编号在各校本中归属不一。
- **〔意译〕说明**：标 `〔意译〕` 的条目为法文原片的核心命题中文转写，并非逐字译文；帕斯卡原文多为凝练的警句与未完成的论证，措辞随译本（如何兆武、郭宏安等中译本）而异。
- **⚠️ 存疑/易误引**：标 `⚠️` 的条目思想意涵确属帕斯卡，但具体表述并非可精确核对的原句，或常见中文流传语与原典有距离，已隔离标注，统计时建议单列。
- **版本依据**：本节编号以 Lafuma 编订的《Pensées》（1951）为蓝本；做严格引用请核对 Sellier 或 Brunschvicg 校本并留意编号差异。
