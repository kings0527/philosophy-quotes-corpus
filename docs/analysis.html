升维聚合：十二条轴上的自我与外界

序 · 升维的意思

单看一个人，得到的是一句格言；单看一个学派，得到的是一套主张。把七十七个人放在一起看，会看到一件更基本的事：

他们争论的从来不是同一个问题。

孔子说「己所不欲勿施于人」、韩非说「法不阿贵，绳不挠曲」、康德说「要这样行动：使你的准则能够同时被当作普遍立法的原则」——表面上都在讲人应该如何对待他人。但三者的差别不是"观点不同"，而是在不同的轴上说话。硬拉到同一个平面比高低，就像比较"三角形更圆还是方形更圆"。

升维就是：不问"谁对"，只问"他在哪个轴上说话"。

1.2 语料库在要求的、八轴接不住的四条

翻了 4505 条语句，有四类材料在八轴里无处安放：

关系 / 实体「此有故彼有，此生故彼生」（缘起）／「众因缘生法，我说即是空」／「君臣父子」— 全都预设"关系先于个体"；而「原子与虚空」／「我思故我在」／「单子」预设"个体先于关系"

第二篇 · 十二轴上的聚合

A 组 · 本体轴

A1 · 界线轴：自我在哪里结束，世界从哪里开始

聚合命题：内外同构不是玄学，而是「反省深度」的函数。而且这条轴上只有三个站位，没有第四种。

多样本

未分（同构极）

  • 「天地与我并生，而万物与我为一。」——《庄子·齐物论》
  • 「你未看此花时，此花与汝心同归于寂；你来看此花时，则此花颜色一时明白起来。」——王阳明《传习录》下
  • 「同一者，既为可思者，亦为存在者。」——巴门尼德《论自然》残篇 DK B3
  • 「观察者即被观察者。」——克里希那穆提
  • 「梵我一如。」——商羯罗《梵经注》系
  • 「我的灵明，便是天地鬼神的主宰。」——王阳明《传习录》下

二分（对应极）

  • 「白马非马。」——《公孙龙子·白马论》
  • 「白马非马」式的名实二分，在西方对应「凡是不可说的，必须保持沉默」。——维特根斯坦《逻辑哲学论》7
  • 「根本不存在『事实』，只有解释。」——尼采遗稿（KSA 12, 7[60]）

统一（更高的同构）

  • 「人是应当被超越的。」——尼采《查拉图斯特拉如是说·序言》（自我成为世界的一部分，同时又超越它）
  • 「实体，我理解为在自身内并通过自身而被认识的东西。」——斯宾诺莎《伦理学》第一部·界说三（心与物是同一实体的两个属性）

升维

这一轴上重要的不是谁对，而是：「未分」这个站位，在印度、中国、希腊三个没有互相影响的传统里独立出现了。

  • 印度：梵我一如、缘起
  • 中国：庄子的齐物、王阳明的岩中花树
  • 希腊：巴门尼德的思在同一

三条独立路线，在反省推到尽头时，都落到了"内外不分"。这说明它不是某个文化的特色，而是反省到极限时的必然落点。

而"二分"不是反对——是换取可操作性所付的代价。公孙龙、休谟、分析哲学都选择了把内外之间的界面本身当作研究对象（名、语言、逻辑）。界面清楚，才能精确；代价是永远碰不到界面两侧的东西。

所以三个站位正好是黑格尔的三段：

` 主客未分 → 主客二分 → 主客统一 庄子、龙树 公孙龙、休谟 康德、王阳明、斯宾诺莎 商羯罗 维特根斯坦 黑格尔 `

多层解释

  • 个体层：一个人在"向内看"上能走多深，决定他站哪个站位。
  • 派别层：修行传统（道、佛、心学、斯多亚、吠檀多）天然落在"未分"；逻辑—经验传统（名实、分析哲学、经验论）天然落在"二分"。
  • 维度层：这三个位置穷尽了可能性。 你不可能同时"内外不分"又"内外严格二分"。这条轴是整张图的第一刀——它决定了后面十一条轴在什么空间里展开。

A2 · 关系轴：关系先于实体，还是实体先于关系

聚合命题：这条轴决定了「我是谁」有没有独立答案——进而决定了伦理学是义务型还是权利型。

多样本

关系先于实体（关系本体论）

  • 「此有故彼有，此生故彼生；此无故彼无，此灭故彼灭。」——《杂阿含经·卷十二》
  • 「众因缘生法，我说即是空。」——龙树《中论·观四谛品》
  • 「父子有亲，君臣有义，夫妇有别，长幼有序，朋友有信。」——《孟子·滕文公上》（人首先是五种关系中的人）
  • 「人是政治动物。」——亚里士多德《政治学》
  • 「人是一切社会关系的总和。」——马克思《关于费尔巴哈的提纲》第六条
  • 「权力来自下面。」——福柯《性史》第一卷
  • 「满街都是圣人。」——王阳明《传习录》下（圣性在关系中显现，不在孤立个体中）

实体先于关系（实体本体论）

  • 「只有一条探究之路可陈说：它存在，且不可能不存在。」——巴门尼德《论自然》残篇 DK B2（唯一实体，无关系可言）
  • 「依约定而有甜与苦、热与冷、色；实际上只有原子与虚空。」——德谟克利特《残篇》DK B117
  • 「我思故我在。」——笛卡尔《谈谈方法》第四部分（我在一切关系之前就已确定）
  • 「单子没有窗户。」——莱布尼茨《单子论》系（每个个体自足，关系是表象）
  • 「它既非曾是，亦非将成；它整个地、同时地、唯一地、连续地在。」——巴门尼德（一的、连续的、无部分的）
  • 「人是会思想的芦苇。」——帕斯卡《思想录》（个体自足地面对无限空间）

升维

这条轴上真正被决定的，不是"世界什么样"，而是「我是谁」这个问题有没有独立于关系的答案。

关系本体实体本体
「我是谁」无独立答案。答案在关系里——我是某人的子、某人的父、某群的一员有独立答案。我思故我在，我在一切关系前已成立
伦理学的形态义务型：角色伦理（父慈子孝）、缘起伦理（不害）权利型：天赋人权、绝对命令
自由的形态自由 = 恰当地处在关系中（「从心所欲不逾矩」）自由 = 不受关系约束（「挣脱一切依附」）
对应的病个体被关系吞没（"乡愿"、集体主义之弊）关系被个体掏空（原子化的孤独、萨特式"他人即地狱"）

这就把中西伦理学差异的根源讲清楚了。 不是"中国重集体、西方重个人"这种粗糙说法，而是：

儒家与佛教预设了关系本体论，所以它们的伦理学必然是义务型的、角色化的；笛卡尔与洛克预设了实体本体论，所以他们的伦理学必然是权利型的、契约化的。两者都是各自本体论的忠实推论。

而且双方各自有盲点，且互为解毒剂：

  • 关系本体看不见"关系之外的个体"，所以需要实体本体来设立底线权利（不能被关系吞没的那一点）。
  • 实体本体看不见"个体之外的关系"，所以需要关系本体来说明意义的来源（萨特的"他人即地狱"正是实体本体走到尽头的病）。

升维结论：中西伦理之争，不是价值之争，是本体论之争。 谁对取决于"人首先是关系还是实体"——而这个问题，本语料库给出了分歧本身作为答案。

多层解释

  • 个体层：一个人默认已把自己理解为"独立核"还是"关系中的位置"，决定了他一生的伦理取向。
  • 派别层：儒家、佛家、马克思、阿伦特在关系侧；巴门尼德、德谟克利特、笛卡尔、莱布尼茨、帕斯卡、洛克在实体侧。
  • 维度层：两种本体论都有不可替代的功能，且各自的失效条件明确。这解释了为什么历史上两者总是交替出现——原子化危机后回归关系论，关系压迫后回归个体权利。

A3 · 时间轴：存在物是恒常的，还是流变的

聚合命题：没有真正的「恒常派」和「流变派」——所有人都是分层的时间论者。分歧只在于「把哪一层设为不变」。而那一层，就是他的第一原理。

多样本

表面上的两端

  • 「它既非曾是，亦非将成；它整个地、同时地、唯一地、连续地在。」——巴门尼德《论自然》残篇 DK B8
  • 「步入同一河流的人，遭遇的是不同的、一再更新的水。」——赫拉克利特《残篇》DK B12
  • 「一切行无常，一切法无我，涅槃寂静。」——释迦牟尼《杂阿含经·卷三》（三法印）
  • 「宇宙即变化，生命即意见。」——马可·奥勒留《沉思录》卷四·3
  • 「人生天地之间，若白驹之过隙，忽然而已。」——《庄子·知北游》
  • 「飘风不终朝，骤雨不终日。」——《道德经·第二十三章》

升维

顺着看，这是最根本的对立。但把每一家的话读完，会发现没有任何一家是真的"全变"或"全不变"：

人物什么在变什么不变
巴门尼德现象（凡人的意见世界）存在者（唯一、不动、圆满）
赫拉克利特万物逻各斯（虽永恒，人却不悟）
释迦牟尼一切行（有为法）缘起法本身——「若佛出世，若未出世，此法常住」
斯多亚万物流变命运 / 逻各斯（严格决定）
老子万物道（「独立而不改，周行而不殆」）
柏拉图现象界理念
康德现象界先验范畴与道德律

升维结论一：所有人都是分层的时间论者。 「恒常 vs 流变」不是一条二值轴，而是一条「你把不变量设在哪一层」的轴。

升维结论二：那一层就是不变量，就是该体系的第一原理。

这不是巧合。任何一个能自洽的思想体系，都必须有一个不动的支点——否则推理由此失去地基（你无法用一个在变的东西去衡量另一个在变的东西）。所以：

  • 巴门尼德的不动点 → 存在
  • 佛家的不动点 → 缘起法
  • 儒家的不动点 → 天 / 人伦
  • 康德的不动点 → 先验形式
  • 现代科学的不动点 → 自然律

升维结论三：所谓"形而上学不可避免"，说的是这个。 你可以宣布"我不设立第一原理"，但"一切都在变"这句话本身若为真，它就是不动的——你已经设立了一个。

这条轴因此是整张图里最有"爆破力"的：它把形而上学从"过时的思辨"变成了"任何体系都必须支付的入场费"。分歧不在"要不要地基"，只在"地基打在哪个深度"。

多层解释

  • 个体层：一个人的"不动点"落在哪一层，决定他在剧变中的稳定性来源。
  • 派别层：佛家把不动点设在"法"（规律）而非"物"（实体），这是最精巧的设计——它让规律不依赖任何实体的持存。
  • 维度层：时间轴与 A2 关系轴独立——斯多亚是"流变 + 关系"（万物相互交织），巴门尼德是"恒常 + 无关系"（一是连续的、无部分的），笛卡尔是"实体恒常 + 关系次要"。四种组合都有实例。

B 组 · 结构轴

B1 · 纵深轴：自我分为几层，杠杆在哪一层

聚合命题：各家分层数量不同，但结构同形——外层（身/感）、中层（情/意）、内层（心/性/灵）。而且向内一层，控制杠杆翻倍，可观测性减半。

多样本

传统分层方案出处
荀子心为形之君「心者，形之君也，而神明之主也。」《荀子·解蔽》
王阳明身 → 心 → 意 → 知 → 物「身之主宰便是心，心之所发便是意，意之本体便是知，意之所在便是物。」《传习录》上
释迦牟尼五蕴「观色如聚沫，受如水上泡，想如春时焰，行如芭蕉，识如幻。」《杂阿含经·卷十》
商羯罗五鞘《梵经注》系（食物、气、意、识、喜）
柏拉图灵魂三分欲望 / 激情 / 理性，《理想国》
亚里士多德三级灵魂营养 / 感觉 / 理性，《论灵魂》
老子身 → 心 → 道「吾所以有大患者，为吾有身；及吾无身，吾有何患？」《道德经·第十三章》
庄子形 → 知 → 道「堕肢体，黜聪明，离形去知，同于大通，此谓坐忘。」《庄子·大宗师》

升维

层数不重要（三家、五层、三级都有），重要的是两条规律：

规律一：越内层，控制杠杆越大。 荀子说"心者形之君"——心是身体的君主。王阳明说"意之所在便是物"——意的指向决定物的呈现。改外层要用力，改内层只需一念。

规律二：越内层，越难观测，而且内外界限越模糊。

  • 最外层（身、感觉）——清清楚楚是"我的"
  • 中层（情绪、意念）——半是我的
  • 最内层（心、性、良知、识）——说不清是谁的：王阳明说"良知是造化的精灵，生天生地"；释迦牟尼说"识"是缘起的一环、没有主人；庄子说"吾丧我"。

两条规律合起来，给出这一轴与 A1 界线轴的耦合：

` 向内一层：控制杠杆 ×2 ｜ 可观测性 ÷2 ｜ 内外界限 ÷2 `

越往内走，"认识你自己"和"认识世界"越是同一句命令。 这就解释了为什么苏格拉底只教人认识自己、龙树只讲一切法空——两人说的其实是同一件事。

多层解释

  • 个体层：修到第几层，决定他能看见什么。停在情绪层的人只能讲修养；到心性层的人才讲得出宇宙论。
  • 派别层：内向路（儒道佛心学）逐层深入；外向路（法墨名兵）停在外层——不是他们浅，而是目标函数不同（要治的是外部秩序，不需要深入内层）。
  • 维度层：分层提供了一组控制杠杆。任何治理方案（治身、治心、治国）本质上都是在选择"在哪一层施加干预"。这与 D3 干预轴正交——这里选深度，那里选位置。

B2 · 信道轴：认知是编码与传输，必有损耗

聚合命题：「言不尽意」不是遗憾，而是信道定理。任何名言都是降维，任何理解都是升维。

多样本

编码必然损耗

  • 「道可道，非常道；名可名，非常名。」——《道德经·第一章》
  • 「知者不言，言者不知。」——《道德经·第五十六章》
  • 「大音希声，大象无形。」——《道德经·第四十一章》
  • 「荃者所以在鱼，得鱼而忘荃；言者所以在意，得意而忘言。」——《庄子·外物》
  • 「书不尽言，言不尽意。」——《周易·系辞》系（王弼《周易注》所本）
  • 「我的语言的界限意味着我的世界的界限。」——维特根斯坦《逻辑哲学论》5.6

接收端决定能否收到

  • 「上士闻道，勤而行之；中士闻道，若存若亡；下士闻道，大笑之。」——《道德经·第四十一章》
  • 「井蛙不可以语于海者，拘于虚也；夏虫不可以语于冰者，笃于时也；曲士不可以语于道者，束于教也。」——《庄子·秋水》
  • 「有教无类。」——《论语·卫灵公》
  • 「辞达而已矣。」——《论语·卫灵公》（编码的最小化原则）

绕过语言

  • 「不立文字，直指人心。」——禅宗（慧能《坛经》系）
  • 「如人饮水，冷暖自知。」——《坛经》系
  • 「得意忘言」——王弼《周易注》
  • 苏格拉底不著书，只口头诘问；释迦牟尼「说法四十五年」而不立文字——两位最伟大的教师都没有留下亲笔
  • 「诘之曰：何故为乐？」的驳问体 vs 「道在屎溺」的极端具象化——降低编码层级以匹配接收端

升维

「言不尽意」不是语言的缺陷，是信道容量定理在人类认知上的形式。

` 体验（高维、连续、具身） ↓ 编码：必须降维、离散化 语言（低维、离散、公共） ↓ 传输：信道噪声、接收端解码能力 理解（再次升维，但已非原物） `

每一步都不可逆。 所以：

升维结论一：一切名言都是降维，一切理解都是升维。 这就是为什么"说得越准确，越不像原来的体验"。

升维结论二：各家发展出两种应对策略，恰好对应通信工程的两条路——

策略做法代表
提高信噪比减少编码层级，用最少的符号承载最多的信息孔子「辞达而已矣」；禅宗「不立文字」；庄子「得意忘言」
提高接收端灵敏度不追求说得更清楚，而追求听得进去孔子「有教无类」；释迦牟尼「应机说法」（对不同根器说不同法）；苏格拉底的对症诘问

升维结论三：「沉默」不是没有内容，是拒绝降维。

苏格拉底不著书、释迦牟尼不立文字、禅宗"不立文字"、维特根斯坦"必须保持沉默"——四种文化、同一个动作。他们把沉默当作对高维内容的保护：与其降维失真，不如不传。这是信息论意义上的主动放弃传输。

这条轴同时给出了"教育"的哲学定义：教育不是提高信源功率（说得更大声、更权威），而是提高接收端的解码能力。这一条把"有教无类"和"因材施教"统一起来了——前者是把接收端扩展到所有人，后者是匹配不同接收端的容量。

多层解释

  • 个体层：一个人能否传达自己，取决于他愿不愿意降到听众的编码层级（"辞达而已矣"是极高的自我约束）。
  • 派别层：口传传统（苏格拉底、毕达哥拉斯派、早期佛教、禅宗）vs 文本传统（亚里士多德、儒家经学、经院哲学）——口传保守，文本扩散。
  • 维度层：这条轴是对 A1 界线轴的技术性补充。A1 说内外是否相通，B2 说就算相通，能不能传出去。这是新的独立约束。

B3 · 边界轴：哪里够不到

聚合命题：认知受三重约束——生命的、结构的、伦理的。而「知道边界在哪里」，本身就是最高一级的认知。

第一重 · 生命的边界

  • 「吾生也有涯，而知也无涯。以有涯随无涯，殆已！」——《庄子·养生主》
  • 「逝者如斯夫，不舍昼夜。」——《论语·子罕》
  • 「非无安居也，我无安心也；非无足财也，我无足心也。」——《墨子·亲士》

性质：认知资源（时间、精力）有限，认知对象无限。这是一个恒定的亏空。

第二重 · 结构的边界

  • 「物自体」不可知。——康德《纯粹理性批判》
  • 「凡人之患，蔽于一曲而暗于大理。」——《荀子·解蔽》
  • 「原因与结果的必然联系，只是习惯的联想。」——休谟《人性论》系
  • 「人心如白板，一切观念来自经验。」——洛克《人类理解论》系
  • 「井蛙不可以语于海者，拘于虚也。」——《庄子·秋水》

性质：认知工具本身（范畴、语言、感官、既有观念）即边界。这不是"还没认知到"，而是"用这套工具永远认知不到"。

第三重 · 伦理的边界

  • 箭喻经：身中毒箭，不应先问「箭谁所射、何木所作」，当急拔箭。——《中阿含经·箭喻经》
  • 「未能事人，焉能事鬼？未知生，焉知死？」——《论语·先进》
  • 「六合之外，圣人存而不论。」——《庄子·齐物论》
  • 「知止不殆。」——《道德经·第四十四章》

性质：有些问题即使能问也不该问——不是无解，而是追问它无益于当下的苦。这是功利性的认知禁界。

升维

认知的最高成就不是知道得更多，而是知道"哪些不知道是可以接受的"。

这一结论跨文明收敛，但用了完全不同的理由：

文明人物为什么接受边界
希腊苏格拉底承认无知才是智慧的开端
希腊康德物自体在原理上不可知
中国庄子以有限追无限必败
中国孔子人事比鬼神更要紧
印度释迦牟尼追问形而上无益于离苦
英国维特根斯坦语言到不了那里

六个人、六个理由、一个结论。

升维结论：康德的伟大不在于越过边界，而在于把边界本身变成了对象——他画出了物自体的位置。这是这一轴上最高级的动作：

认知的扩张不是靠突破边界，而是靠把边界本身变成研究对象。

成立的反面：独断体系（经院哲学的过度推演、汉代谶纬、各种包治百病的"完备理论"）之所以僵化，正是因为拒绝了第一重与第二重边界。

多层解释

  • 个体层：能否忍受"不知道"，决定一个人会不会走向独断。
  • 派别层：三层边界各有其对应——生命边界催生道家与斯多亚；结构边界催生康德与维特根斯坦；伦理边界催生佛教与儒家。
  • 维度层：约束不是认知的失败，而是认知的形状。 有了边界，内部才有结构。

升维

通常这张轴上只有两个位置：决定论（斯多亚、荀子）与偶然论（伊壁鸠鲁的原子偏斜）。

但佛家的"缘起"给出了第三个位置，而且它才是最有解释力的：

` 决定论：结果 = f(充分且必要的先定因) 随机论：结果 = f(无因) 缘起： 结果 = f(诸条件具足) ← 既非注定，也非无因 `

"缘起"的关键在于三条否定的同时成立：

  1. 否定恒常因（不是"注定"）——因为条件可以改变。
  2. 否定无因（不是"偶然"）——因为条件具足则必生。
  3. 否定第一因（没有"造物主"）——「非梵天、非自在天」。

这三条合起来，正是现代概率因果的定义：结果由条件分布决定，而非由某个先定值决定。

所以佛家在两千五百年前就逼近了"概率因果"的哲学版本。而且它比概率因果多做了一件事：它把"能改什么"讲清楚了——你改不了结果的定值，但你能改变条件。这就是「不可胜在己，可胜在敌」的同一个洞察（孙子）和「祸福相倚」（老子）的同一个洞察。

升维结论：这张轴真正的分野，不在「是否被决定」，而在「你认为可以改变什么」。

可改变的不可改变的因此的实践态度
斯多亚我的判断命运、外物宁静（不动心）
墨子几乎一切（除非命定）命（但命不存在）强力从事
荀子天（可"制天命而用之"）天的规律应之以治则吉
佛家条件（业、缘）已生之果修因
老子我（无为、知止）天道（损有余补不足）柔弱守静
存在主义一切（自由即责任）境况（situation）承担

同一个"可改变"的结构，六种不同的实践方案。

多层解释

  • 个体层：一个人对自己"能改变什么"的判定，直接决定他的行动强度与幸福感。
  • 派别层：墨家是最激进的能动论（反命、强力），斯多亚是最彻底的决定论（顺命、不动心），佛家是最精细的条件论（修因）。
  • 维度层：这三条路在逻辑上不互相否定——你可以同时相信"大的规律不可违"和"局部的条件可改"。所以真实的差别不在真理，而在你选择在哪一级上用力。

聚合命题：各家在「心灵原本带了多少东西」上的分歧，决定了他们的更新方式。而修行，很大程度上就是调节先验强度的操作。

升维

用更新的语言重述这三组：

先验强度更新特征优势风险
厚（孟子、王阳明、柏拉图、笛卡尔、康德）收敛快，少量经验即可判定自足、抗噪、内心稳固听不进反证，易成独断
薄（洛克、休谟、亚里士多德、荀子）收敛慢，依赖经验积累可修正、开放易被环境塑形，易成相对主义
零（龙树、克氏、释迦牟尼、老子、庄子）拒绝收敛，持续悬置不被任何预设绑架无法据以行动

升维结论一：所谓"修行"，很大一部分是调节先验强度的操作。

  • 孟子的「求其放心」、王阳明的「致良知」 = 把先验调厚（唤醒自带的判断力）
  • 荀子的「劝学」、洛克的「白板」 = 保持先验薄，靠积累
  • 庄子的「坐忘」、龙树的「空」、老子的「为道日损」 = 把先验清零

三种操作没有优劣，对应三种处境：

` 处境稳定、需要快速决断 → 调厚（王阳明式） 处境陌生、需要探索 → 调薄（荀子式） 处境本身有病、预设即病根 → 清零（龙树式） `

升维结论二（重要）：人不会始终停留在一种先验强度上。

苏格拉底是薄先验（诘问、承认无知）却把"德性即知识"设成厚先验；庄子是零先验却守着"道"这一条不可动摇的支点。所以更准确的说法是：

每个人在"我"这个对象上是厚先验，在"世界"这个对象上是薄先验——或反之。

这与前面「对外用概率、对内用命令」是同一件事的两面。这条轴把修养从"德性问题"变成了"参数问题"——而参数可以自陈、比较、调整。

多层解释

  • 个体层：一个人的先验厚度决定他的学习速度与抗说服能力，两者成反比。
  • 派别层：心学与唯理论天然厚先验；经验论与考据学天然薄先验；佛道与神秘主义传统天然零先验。
  • 维度层：先验强度是可调的参数，不是天生的性格。人可以主动"损"或"致"。它与 A3 时间轴正交——A3 问"哪一层不变"，C2 问"心灵带着多少来"。

升维

设计论涌现论
秩序的来源立法者的蓝图、圣人的礼制无数局部互动自发形成
对改造的态度可以重新设计（变法、改制）任何全局改造都危险
速度极快（一纸法令）极慢（需要世代积累）
失效条件环境剧变时蓝图作废（秦二世而亡）需要集中行动时无从下手（无法应对大灾、大战）
认知上的气质相信理性可以穷尽社会承认理性无法穷尽社会

升维结论一：涌现论天然反乌托邦。 如果秩序是无数局部互动涌现的，那么任何自称掌握全局蓝图的方案都必然在某个局部出错，而且错了无法就地修正——因为蓝图不容许局部偏差。老子「为者败之，执者失之」和庄子「天下神器，不可为也」，说的就是这个。

升维结论二：设计论与涌现论的对立，本质上是「认知能力自信度」的对立。 这把它和 B3 边界轴接上了：

` 若认为认知边界宽（能看到全局） → 设计论（韩非、墨子、董仲舒） 若认为认知边界窄（看不到全局） → 涌现论（老子、庄子、郭象） `

所以"该不该有为"这个中国思想史的核心争论，可以还原成一个关于认知边界的判断。 这是这一轴最有价值的提升——它把政治哲学问题转成了认识论问题。

升维结论三：涌现轴解释了道家的"无为"为什么不是懒惰。 「无为」不是不做事，而是不施加全局性的、不可局部修正的干预。它的对应工程学概念是分布式鲁棒控制——每个局部只根据局部信息做局部调整。这恰好与 D3 干预轴上的"取消控制器"是同一个设计。

多层选择

  • 个体层：一个人是否相信"人生可以规划"，是这条轴的个体版本。
  • 派别层：法家、墨家、董仲舒、黑格尔在设计侧；老子、庄子、郭象、斯多亚（逻各斯内在于万物）在涌现侧。
  • 维度层：这条轴是初版遗漏的、最有政治解释力的一条。 它把"无为而治 vs 以法为教"从价值之争还原为认知边界判断之争。

D 组 · 实践轴

D1 · 互动轴：他人是对手还是伙伴

聚合命题：各家在「人性能否改变」上的分歧，其实是对「博弈结构」的假设不同。性善性恶之争，可以还原为「这个场域要重复几次」之争。

多样本

纯博弈假设（一次性、信息不对称）

  • 「法不阿贵，绳不挠曲。法之所加，智者弗能辞，勇者弗敢争。」——《韩非子·有度》
  • 「壹刑者，刑无等级。」——《商君书·赏刑》
  • 「人主莫不欲其臣之忠，而忠未必信。」——《庄子·外物》

合作假设（无限重复）

  • 「己所不欲，勿施于人。」——《论语·颜渊》
  • 「夫爱人者，人必从而爱之；利人者，人必从而利之。」——《墨子·兼爱中》
  • 「以德服人者，中心悦而诚服也。」——《孟子·公孙丑上》
  • 「君子之交淡若水，小人之交甘若醴。」——《庄子·山木》
  • 「以利合者，迫穷祸患害相弃也；以天属者，迫穷祸患害相收也。」——《庄子·山木》

冲突假设（注视即斗争）

  • 「他人即地狱。」——萨特《禁闭》
  • 「凡人皆以自我为中心」的韩非式前提

共在假设（行动与公共领域）

  • 「我反抗，故我们存在。」——加缪《反抗者》
  • 「人是政治动物。」——亚里士多德《政治学》
  • 「圣人与天地民物同体。」——王阳明《传习录》下

升维

表面上，韩非与孔子在争"人性本恶还是本善"。换成博弈语言，两人其实在描述两种不同的博弈结构：

韩非孔子 / 墨子 / 孟子
博弈次数一次性（一次失手即亡国）无限重复（世代延续的人伦）
参与人君 vs 臣，权力不对等对等的伦理共同体
信息不可观测（臣必欺君）长期可观测（「听其言而观其行」）
最优策略背叛（以法防欺）合作（以仁育信）

双方都是对的——在各自的博弈结构里。

  • 一次性博弈中，背叛是占优策略。韩非没有看错人性，他只是假设了一个一次性的场域（君臣）。
  • 无限重复博弈中，合作是均衡。孔子没有天真，他只是假设了一个无限重复的场域（父子、世代）。

升维结论：这把两千年的"性善性恶"之争，还原成了一个可讨论的问题——这个场域实际上要重复几次？

四家因此成了一个连续的工程谱：

` 韩非：承认结构，用法强制收敛 荀子：改造结构，用礼法生成重复（"明分使群"） 孔子：依赖结构，用人伦承载重复 孟子：信任结构，用四端发动合作 `

荀子的位置最精巧——他不争论人性，直接动手改造博弈结构。「化性起伪」的"伪"（人为），本质上是把一次性博弈改造成重复博弈的工程。

多层解释

  • 个体层：一个人对他人的默认策略（防 / 信），来自他对自己所处场域重复次数的判断。
  • 派别层：法家服务君主单点（一次性），儒家服务宗族网络（无限重复），墨家服务跨国游士群体（中等重复），存在主义服务无依托的现代个体（无既有场域）。
  • 维度层：不存在"正确的策略"，只存在"对场的正确判断"。 诸位哲学家真正的差异，是他们对"场"的判断不同。这与 C1 模态轴相连——对"能改变什么"的判断，正是对"场"的判断。

D2 · 尺度轴：什么被淘汰，什么活下来

聚合命题：认知能力本身要接受适应性检验。而庄子发现了进化中最深的悖论——最有效的适应，往往不是最强的适应。

多样本

认知是适应器

  • 「君子生非异也，善假于物也。」——《荀子·劝学》
  • 「力不若牛，走不若马，而牛马为用，何也？曰：人能群，彼不能群也。」——《荀子·王制》
  • 「水火有气而无生，草木有生而无知，禽兽有知而无义；人有气、有生、有知，亦且有义，故最为天下贵也。」——《荀子·王制》
  • 「恻隐之心，人皆有之；羞恶之心，人皆有之。」——《孟子·告子上》（道德是先天的适应器）
  • 「良知良能，愚夫愚妇与圣人同。」——王阳明《传习录》中

反工具理性

  • 「人皆知有用之用，而莫知无用之用也。」——《庄子·人间世》
  • 「山木自寇也，膏火自煎也。桂可食，故伐之；漆可用，故割之。」——《庄子·人间世》
  • 「巧者劳而知者忧。」——《庄子·列御寇》系
  • 「大直若屈，大巧若拙，大辩若讷。」——《道德经·第四十五章》

限知 = 生存策略

  • 「知止不殆。」——《道德经·第四十四章》
  • 「知足者富。」——《道德经·第三十三章》
  • 「养心莫善于寡欲。」——《孟子·尽心下》
  • 「少有所欲者，近于神。」——德谟克利特《残篇》DK B80
  • 「君子役物，小人役于物。」——《荀子·修身》
  • 「五色令人目盲，五音令人耳聋，五味令人口爽。」——《道德经·第十二章》
  • 「欲虽不可尽，可以近尽也。」——《荀子·正名》

升维

各家具体主张不同，但在同一个动作上完全一致：主动限制认知与欲望的范围。

原因是资源约束下的收益递减：

` 认知的边际收益：递减 认知的边际成本：不递减（时间、精力、焦虑） → 存在一个最优停止点 `

这个最优停止点，各家给了不同的名字：

名字出处限制的对象
知止《道德经》44对世界的探查
寡欲《孟子·尽心下》对外的索取
无记《中阿含经·箭喻经》形上追问
阙疑《论语·为政》系知识的边界
中道亚里士多德《尼各马可伦理学》一切过度
无用之用《庄子·人间世》工具化

升维结论一：「知止」不是道德要求，是生存策略。 所以它跨道、儒、佛、希腊四家独立出现。

升维结论二（最深的一条）：庄子发现了进化中的反适应悖论。

「桂可食，故伐之；漆可用，故割之。」
因为有用，所以被杀。
「人皆知有用之用，而莫知无用之用也。」
活下来的常常是"不材"。

这条观察把"顺其自然"从消极态度提升为一种反脆弱的生存策略：不把全部能力投入单一用途，保留"不可被利用"的余地。

这在生态学上正是"广适性优于特化"——特化物种在稳定环境中效率最高，在环境剧变时最先灭绝。庄子的"无用"就是不对环境做特化承诺。

升维结论三：这条轴给哲学提出了一个比"求真"更硬的标准——

这套哲学能不能让信奉它的人活下来、传下去？

注意：这条标准并不否定求真，它只是加了一层筛选。真理性的东西未必能存活（苏格拉底被处死），能存活的未必真。但一个宣称"应当如此生活"的哲学，若它让人活不下去，那它至少是不完整的。

多层解释

  • 个体层：一个人能否主动设限，决定他会不会被自己的欲望与求知欲拖垮。
  • 派别层：道家、伊壁鸠鲁、斯多亚、佛家都把"限知 / 限欲"作为核心法门。值得注意的是，语料库里没有一个代表人物站在"认知应该无限扩张"这一侧——培根式的"知识就是力量"在 77 人中缺席。这是一个值得记录的思想史空白。
  • 维度层：它与 C3 涌现轴正交——庄子既是"涌现论"（道在屎溺）也是"限知论"（无用之用），但两者独立：一个谈秩序来源，一个谈适应策略。

D3 · 干预轴：控制器放在哪里

聚合命题：四类方案的差别只在「控制器放在哪里、误差信号从哪来」。而这四个位置穷尽了设计空间。

四种位置

① 控制器外置（法）

  • 「法不阿贵，绳不挠曲。」——《韩非子·有度》
  • 「壹刑者，刑无等级。」——《商君书·赏刑》
  • 误差信号：是否违法。修正动作：刑罚。
  • 特征：开环。规则一旦设定，不采集关于自身的反馈。

② 控制器内置（心）

  • 「吾日三省吾身：为人谋而不忠乎？与朋友交而不信乎？传不习乎？」——《论语·学而》
  • 「知是行之始，行是知之成。」「知而不行，只是未知。」——王阳明《传习录》上
  • 「困扰你的不是这件事，而是你对它的判断。而这个判断，你随时可以撤销。」——马可·奥勒留《沉思录》卷八·47
  • 「有一样东西在我们能力之内，另一些不在。」——爱比克泰德《手册》
  • 特征：闭环负反馈，且把调节点放在"判断层"而非"事件层"——这是斯多亚最精妙的设计：世界不动，我不动，误差在判断层被消掉。

③ 控制器超验化（理 / 天）

  • 「天行有常，不为尧存，不为桀亡。」——《荀子·天论》
  • 「天不变，道亦不变。」——董仲舒
  • 「存天理，灭人欲。」——朱熹《朱子语类》系
  • 「凡合乎理性的都是现实的，凡现实的都是合乎理性的。」——黑格尔《法哲学原理》序言
  • 特征：控制器被外推到不可修改的位置，因此最稳定，也最慢。

④ 取消控制器（自然）

  • 「我无为而民自化，我好静而民自正。」——《道德经·第五十七章》
  • 「人法地，地法天，天法道，道法自然。」——《道德经·第二十五章》
  • 「天下神器，不可为也。为者败之，执者失之。」——《道德经·第二十九章》
  • 斯宾诺莎：自由是对必然的认识。——《伦理学》
  • 特征：不开环也不闭环，完全依赖系统的自组织（与 C3 涌现轴直接相连）。

升维

这四种位置穷尽了设计空间。

任何治理方案（治身、治心、治家、治国、治天下）都必然落在其中之一或组合其中之几。你能提出的"新方案"，只能在四者之间换配比，不可能是第五种。

为什么？因为控制论上只有三个变量需要安排：

` ① 误差信号从哪来？（外部行为 / 内部判断 / 形上法则 / 不采集） ② 控制器能否被自己修改？（能 / 不能） ③ 修正动作发生在哪一层？（行为 / 判断 / 制度 / 不干预） `

三种排布只有四个自洽解——就是上面四类。

升维结论（最有用的部分）：控制器越靠外，收敛越快但适应性越差；越靠内，收敛越慢但越能适应剧变。

方案收敛速度适应性失效条件
外置（法）极快极差环境剧变（秦二世而亡）
内置（心）慢极强需要长期教化
超验（理）最慢强超越者被怀疑（近代理性冲击经学）
无控制器（自然）不确定最强无法应对需要集中行动的危机

这张表能解释中国思想史的走向：乱世先取法家（求快），治世转儒家（求稳），崩解时道家出场（求适应），重整时理学接手（求合法性）。

多层解释

  • 个体层：个人修养法门 = 在四者中选一个作为主控制器。
  • 派别层：法家 = ①，儒家心学 = ②，宋明理学与基督教神学 = ③，道家与斯宾诺莎 = ④。
  • 维度层：这条轴把"修养"从道德问题还原成工程问题——你要的是快，还是稳？ 它与 B1 纵深轴正交：这里选位置，那里选深度。

第三篇 · 统合

3.1 十二轴的独立性检验

十二条轴不是拍脑袋定的——每一条都必须能举出真实人物，证明四种组合都可行。抽查几个关键交叉：

交叉组合一组合二证明独立性
A3 时间 × C1 模态斯多亚：流变 + 严格决定墨子：流变 + 反宿命「变不变」与「定不定」是两件事
C3 涌现 × D3 干预老子：涌现 + 无控制器郭象：涌现 + 无控制器（同侧）／荀子：设计 + 内置控制器秩序来源与干预位置可分离
A2 关系 × A3 时间斯多亚：关系 + 流变巴门尼德：无关系 + 恒常关系论不必是流变论
B1 纵深 × D3 干预荀子：深层（心为形之君）+ 外置（礼法）王阳明：深层 + 内置深度与位置可分离

只有 B1 与 A1 存在真实的耦合（越深越不分内外），这是十二条轴中唯一一处结构性关联——而它不是重叠，是一条可检验的预测。

3.2 十二轴归约为五个问题

十二条轴合起来，收敛成五个必须表态的问题：

#问题由哪些轴构成
①我在哪里结束，世界在哪里开始？A1 界线 + A2 关系
②哪一层不动？A3 时间 + B1 纵深
③秩序和知识从哪里来？B2 信道 + C2 更新 + C3 涌现
④我能改变什么，必须接受什么？C1 模态 + D1 互动 + D2 尺度 + D3 干预
⑤我到哪里去？目的（v3 新增）

这五个问题穷尽了"一个人必须表态的东西"。 你不可能不回答它们——不回答本身就是一种回答（取默认值：界线=二分、不动层=常识、来源=经验、可改变=直觉、目的=随大流）。这就是为什么每个人都有哲学，哪怕他不自称有。

→ 一个学派，就是坐标完全重合的一群人。「被并称」不是文学修辞，是坐标事实。

  • 程颢 vs 陆九渊：只差两栏（② 不动层：天·理 vs 心·灵魂；③ 秩序来源：涌现 vs 兼有）。

→ 「理学 vs 心学」这场持续四百年的争论，收敛成两栏。

  • 荀子 vs 苏格拉底：⑤目的相同（都是成德·成圣），其余六栏全不同——同归而殊途。
  • 孔子 vs 韩非：常被并提为「儒法」，实际九栏里有八栏不同——坐标上几乎完全对立。

3.3 归总 · 那一句话

七十七家、四千五百条语句，聚合到十二条轴上，再收敛为五个问题之后：

哲学史上看起来无穷无尽的分歧，是五个问题的取值差异。

① 我在哪里结束？　② 哪一层不动？　③ 秩序和知识从哪里来？　④ 我能改变什么？　⑤ 我到哪里去？

而其中第二个问题最关键。因为：

你选哪一层作为不变的支点，决定了你其余四个问题的答案。

把不动点设在「天」→ 人伦关系成为义务（①）、知识靠积累（③）、可改的是自己（④）、目的是成圣（⑤）——这是儒家。
把不动点设在「法」→ 关系被制度化（①）、知识靠经验（③）、可改的是制度（④）、目的是秩序（⑤）——这是法家。
把不动点设在「缘起」→ 关系先于一切（①）、知识靠条件观察（③）、可改的是因（④）、目的是解脱（⑤）——这是佛家。
把不动点设在「我思」→ 实体先于关系（①）、知识靠理性重构（③）、可改的是整个知识体系（④）、目的是确知（⑤）——这是笛卡尔。

所以"谁是伟大的哲学家"这个问题，升维之后变得没有意义。 真正有意义的问题是：

他在哪里打桩？为什么打在那里？往哪里走？

而这个问题一旦问对，各家的不可比性就消失了——它们变成了同一张表上的不同填法。这，就是升维聚合得到的哲学。

附论 · 终极三问与五问：两个投影，一个补上的缺口

这一节来自一个外部追问：「① 我在哪里结束？② 哪一层不动？③ 秩序和知识从哪里来？④ 我能改变什么？」——这不就是我是谁 / 我从哪里来 / 我到哪里去吗？

这个追问做对了两件事：发现了轴系的一个缺口，也暴露了终极三问自身的一个预设。

一、逐项映射：两项对得上，一项原本缺位

终极三问本文轴系判定
我是谁① 界线 + ① 关系✅ 严格对应
我从哪里来② 不动层✅ 严格对应——第一原理即「我凭什么存在」
我到哪里去原本没有这一格❌ 缺位

四问不是三问的还原，而是分裂成两族：

  • 本体三问（我是谁／从哪来／到哪去）↔ 三问严格对应，前提是补上「目的」
  • 运作两问（秩序从哪来／我能改什么）↔ 三问接不住。它们问的是「怎么运转」，不是「在哪里」

因此补入第⑤问「我到哪里去」，其轴为目的轴（10 个取值）。

三、但终极三问本身不中立

三问看着是三个开放问题，其实它把三个答案写进了题面：

  • 预设有一个持存的、边界明确的「我」——否则「我是谁」问不出来
  • 预设时间有起点——否则「从哪里来」不成立
  • 预设有一个归宿——否则「到哪里去」不成立

这是实体本体论＋线性时间，是一种立场。把它拿去量本库：

预设接受取消
P1 边界明确的自我界线=二分 32 人（42%）界线=未分 34 人（44%）
P2 有来处66 人11 人（缘起·空／道·自然：老子、庄子、龙树、释迦牟尼、王弼、郭象、僧肇、道元…）
P3 有归宿74 人（96%）3 人（当下·无求：海亚姆、吉田兼好、克里希那穆提）

只有四分之一的人是「三问的正宗答题者」——笛卡尔、洛克、休谟、罗素、波普尔、柏拉图、亚里士多德、克尔凯郭尔、萨特。

而 44% 的人主动取消了「我」的边界。对他们，「我是谁」本身要被改写——不是答得不好，是题出错了。

佛家最彻底：「无我」不是说「我是什么」，是说「我」这种提问方式不成立。龙树连空也不立（空亦复空）。庄子说「吾丧我」——那个能被问「我是谁」的东西，他已经不要了。巴门尼德说「它既非曾是，亦非将成」——「从哪里来」这一问被直接废掉。

四、所以那句话要改一个字

有的哲学家在答题，有的哲学家在改题。而改题的人，往往答得更彻底。

他取消问题的方式，同时暴露了他的全部预设：一个说「无我」的人，顺便告诉你他不接受实体本体论；一个说「吾丧我」的人，顺便告诉你他不接受「我」是个可问之物。改题是更高密度的一次回答——它把三问从「求答案」变成了「查前提」。

五、补：这个追问没有解释掉统计问题（一个被自己否证的推测）

由三问的预设出发，有一个很自然的推测：「自我／外界」这个二分本身就建立在实体自我之上，而库里 75% 的人不接受这套预设——所以测量不确定带宽（7.1 pp）可能正来自「框架与对象不匹配」。

这个推测被做成了可证伪假设，并被数据否证（信度检验.py）：

假设检验结果
H3：框架失配者归类不确定度更高界线=二分 31.7% vs 其余 33.9%p = 0.5575，不成立

真因不在被试的框架，在仪器本身的定义模糊——见 升维分析报告.md 与 信度检验.py 一节：v1 判定规则的评分者间信度 κ = 0.150（不可信），换用对象域规则后升至 κ = 0.864。

教训：推测要跑检验，跑完不合格就当撤回。这一条比上面任何一个哲学结论都更值得保留。
