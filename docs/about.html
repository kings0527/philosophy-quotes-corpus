0. 这个项目是什么

把古今中外哲学家、思想家的有出处语句摘录成结构化语料库，供后续做「哲学统计」——比如：统计各派别在「自我认知」与「外界认知」上的比重差异、不同时代的问题意识迁移、中西对比等。

  • 组织方式：先分地域/传统 → 再分人名（一人一文件夹）→ 一人一个 Markdown 文件
  • 全部路径均为仓库内相对路径，文中不含任何本机绝对路径
  • 每人文件内固定含两个维度：
  • A 类 · 对自我的认知（心性、自省、欲望、修养、生死、人格理想、自我价值）
  • B 类 · 对外界的认知（他人、社会、政治、自然、宇宙、知识、语言、因果、价值判断）
  • 每人 ≥ 50 条。

1. 方法与真伪原则（重要，先读）

这一套语料是要拿去做统计的，数据的可靠性决定结论的有效性。因此定三条硬规矩：

① 有出处才收录。 每条语句必须指向具体文献（《论语·为政》、柏拉图《申辩篇》、尼采《善恶的彼岸》等）。凡常见但查无实据的「名人名言」，一律不收，或收进文末「存疑/伪托」栏并明确标注。

② 转述型人物要注明来源性质。

  • 苏格拉底、释迦牟尼本人无著作，语录来自弟子记录（柏拉图、色诺芬 / 佛典结集）。这类文件的出处分两层标注：《申辩篇》38a（柏拉图记述苏格拉底）。
  • 东西方语句存在译本差异，译文标注「参考译本」或标 〔译〕，表示措辞随译本而异、语义无争议。

③ 归属存疑的经典名句单独隔离。 例如「我思故我在」有确定出处（《谈谈方法》/《第一哲学沉思集》），但「存在即合理」是黑格尔「凡是合乎理性的都是现实的」的通俗化改写，必须标注为改写，不能当原句统计。

3. 派别与核心思想速查

儒家：以「仁」为核心，重人伦、礼制、修身与入世。孔子立「仁礼」骨架 → 孟子补「性善/仁政」→ 荀子转向「性恶/礼法」。宋明分为理学（程朱：性即理、格物穷理）与心学（陆王：心即理、致良知）两系。

道家：以「道」为根本，主张自然、无为、超越人为造作。老子重「反」与「柔」，庄子重「齐物」与「逍遥」，魏晋玄学（王弼贵无、郭象独化）把它推向本体论。

墨家：兼爱、非攻、尚贤、节用、非命。先秦「显学」，与儒家并为两大流派，后中绝。

法家：以人性自利为前提，主张法术势并用、以法为教、以吏为师。商鞅重「法」，申不害重「术」，韩非集大成。

名家/阴阳家/兵家：分别处理概念逻辑（白马非马）、宇宙图式（五德终始）、军事对抗（知彼知己）问题。

中国佛学：般若学（僧肇）→ 禅宗（慧能）为佛教中国化的两条主线，「不立文字、直指人心」。

古希腊三大家：苏格拉底把哲学从自然转向人（德性即知识）→ 柏拉图建立理念论 → 亚里士多德分科化、经验化。

斯多亚：区分「可控/不可控」，以理性顺自然，追求内在不动心。爱比克泰德、塞涅卡、奥勒留为罗马三代表。

唯理论 vs 经验论：笛卡尔/斯宾诺莎/莱布尼茨主张知识源于理性；洛克/休谟主张知识源于经验。康德以「先验」调和二者。

德国古典：康德（批判哲学）→ 费希特/谢林 → 黑格尔（辩证法与绝对精神），后分化为叔本华的悲观唯意志论与马克思的实践唯物论。

存在主义一系：克尔凯郭尔 → 尼采 → 海德格尔 → 萨特/加缪。「存在先于本质」「向死而生」「荒诞与反抗」。

分析哲学：弗雷格 → 罗素/维特根斯坦，把哲学问题还原为语言问题。

佛教与中观：缘起→无我→空。龙树以「八不」破一切执，立二谛。

4.4 判定规则（v2，2026-09-21 修订）

⚠️ 本节是全文的关键前置条件。 v1 规则经审计确认不可复现：38.1% 的条目落在两可区，不确定带宽 7.1 个百分点——大于本库任何统计效应。规则不修，后面所有 A/B 比较都无意义。

4.4.1 v1 规则的三个缺陷（审计结论）

缺陷证据
两个独立标准被写成「或」v1 同时用了「句法主语」与「主题域」两个互相独立的标准。320 条（占 A 类 15.0%）有自称词但主题偏 B，被规则的两半同时认领
B 是杂类（catch-all）B 把「他人／社会／自然／宇宙／语言／知识」五个不同对象域塞成一类。而认识论的主体本就是认知者自己——笛卡尔「我思故我在」因此归哪边都不对
补丁无口径地位#self-other 用了 34 条，但 A 类 16 条、B 类 18 条——同一现象被拆到两边。同一个人（陆九渊）「宇宙便是吾心」标 A，「宇宙内事是己分内事」标 B

审计脚本：审查-判定规则.py（可复跑）。实测：

  • 含自称／自指词（我吾己予余自）的条目 1578 条（35.0%）
  • 规则两半打架 320 条（A 类的 15.0%）

4.4.2 v2 规则：拆成两个正交字段，A/B 降级为派生量

字段一 · 对象域（Object）——这条语句在谈论什么

取值判定例
自我关于「我是什么／我应当成为什么」的判断「我思故我在」「仁义礼智我固有之」
他者他人、人际、社会、政治「己所不欲勿施于人」「法不阿贵」
世界自然、宇宙、物「天行有常」「宇宙即变化」
符号语言、名、知识本身「道可道非常道」「我的语言的界限…」
同一我与世界的关系本身「天地与我并生」「世界，是我的表象」

字段二 · 陈述类型（Claim）——这句话在做什么

描述（是什么）／规范（应当如何）／方法（如何做到）

判定用「改写测试」，可复现：把句子改写成「它回答了哪个问题？」

` "我是什么／我应当成为什么" → 自我 "他人／社会应当如何" → 他者 "世界如何运作" → 世界 "我们如何知道／如何言说" → 符号 "我与世界是不是一回事" → 同一 `

以「谈论对象」为准，不以出现的字为准。 三条校正示例：

句子v1 归属v2 归属理由
「己所不欲，勿施于人」A（有「己」）他者回答的是"他人应如何被对待"
「吾尝终日而思矣，不如须臾之所学也」A（有「吾」）符号回答的是"如何获得知识"
「宇宙便是吾心，吾心即是宇宙」两可同一回答的是"我与世界是不是一回事"

A/B 降级为派生聚合（保留与旧数据的可比性）：

` A · 对自我的认知 = 对象域 ∈ {自我} B · 对外界的认知 = 对象域 ∈ {他者, 世界, 符号} 同一 = 对象域 ∈ {同一} ← 单列，不并入 B `

#self-other 由自由手打的补丁升格为机读取值 同一，位置固定在出处之前。

6.2 十二条轴收敛为五个问题

#问题由哪些轴构成
①我在哪里结束，世界在哪里开始？界线 + 关系
②哪一层不动？时间 + 纵深
③秩序和知识从哪里来？信道 + 更新 + 涌现
④我能改变什么，必须接受什么？模态 + 互动 + 尺度 + 干预
⑤我到哪里去？目的（v3 新增）

①②⑤ 合起来就是「我是谁 · 我从哪里来 · 我到哪里去」；③④ 是三问接不住的「运作两问」——它们问的是「怎么运转」，不是「在哪里」。详见 升维聚合哲学.md §附论。

这五个问题穷尽了「一个人必须表态的东西」——不回答本身就是一种回答（取默认值）。每位哲学家的全部主张，都可以表示为这五个问题的一组取值（对照表见 升维聚合哲学.md §3.2）。

6.3 归总

哲学史上看起来无穷无尽的分歧，是四个问题的取值差异。没有第五个问题。

其中第二个问题最关键：你选哪一层作为不变的支点，决定了其余三个问题的答案。
不动点设在「天」→ 儒家；设在「法」→ 法家；设在「缘起」→ 佛家；设在「我思」→ 笛卡尔。

6.4 数据可用性限制与定稿结论（读语料时必看）

一、旧尺子（v1）测出的「无差异」是仪器造成的

v1 规则把「自我／他者／世界／符号」四类不同的谈论对象混成一个 A 类。后果：

  • 两名独立评分者 κ = 0.150（低于 0.20 作废线）
  • 由 κ 推 MDC = 16.9 pp；51%（39/77）的人 A 占比恰好 = 50.0%（纯随机只该 6.7 人）
  • 2926 对比较中，Bonferroni 校正后无一对显著

二、新尺子（v2）与换尺后的对照

新规则只问「这句话在谈论什么」，五选一：自我／他者／世界／符号／同一。 两名独立编码员盲编码 150 条 κ = 0.864；再用不同批编码者的重叠项交叉验证 κ = 0.818 / 0.774。 经此校正后对全库 4505 条重新编码（15 个分片、打乱后编码以消除「编码者偏差与人物混淆」）：

指标v1 旧尺子v2 对象域尺子
全库 A 占比均值47.1%47.2%
个体间标准差6.6 pp19.0 pp
个体间区间跨度33.7 pp91.7 pp
恰好落在 50.0% 的人39 人（51%）2 人（3%）
两两比较可检出（≥MDC）273 对（9.3%）1353 对（46.2%）
Bonferroni 校正后显著0 对422 对

均值几乎未动，个体差异扩大近三倍。 所以此前的「测不出差异」是仪器的产物，不是世界的真相。

三、定稿结论

  1. 「文化决定论」仍不成立。 传统层 η² 从 6.5% 降至 4.2%——差异在个体层。中国内部从王阳明 93% 到孙子 3%，跨度超过任何跨文化比较。
  2. 「内求型」与「外求型」是两种思想类型，不是程度差异。 王阳明 93%、慧能 90%、爱比克泰德 72%、马可·奥勒留 69% ／ 公孙龙 2%、巴门尼德 2%、孙子 3%、商鞅 5%。
  3. ⚠️ 全库 A 占比修正为 47.2%。 此前基于 150 条样本估的「36–40%」是抽样波动，不成立——按样本人物构成加权后为 43.4%，实测 38.7%，差距在 1.2 个标准误内。以全库 4505 条的重编结果为准。

四、仍然成立的三条旧结论

  1. 编排配额截断：旧尺子下 51% 的人恰好 50%，源于编纂时「每维度均衡取条」的配额。这一现象本身是真的，但它掩盖的不是「无差异」而是「差异极大」。
  2. 传承结构仍是强混淆：可靠度 η²=31.2%、文体 η²=26.5%（v1 口径）。残篇在低 A 尾部富集 4.6 倍。
  3. 自然实验：德谟克利特 vs 巴门尼德——同代、同传统、同为残篇，v1 相差 32 pp；v2 相差 49.6 pp（51.6% vs 2.0%）。

五、一个被我自己的数据否证的推测

我曾推测测量不确定带宽来自「框架与被试不匹配」（库里 75% 的人不接受实体自我预设）。 做成可证伪假设后检验：H3 框架失配 p=0.5575、H4 三问预设 p=0.8259，均不成立，已撤回。 真因在仪器定义模糊，不在被试。
