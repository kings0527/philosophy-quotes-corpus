# 哲学统计 · 总览索引

## 0. 这个项目是什么

把古今中外哲学家、思想家的**有出处语句**摘录成结构化语料库，供后续做「哲学统计」——比如：统计各派别在「自我认知」与「外界认知」上的比重差异、不同时代的问题意识迁移、中西对比等。

- 组织方式：**先分地域/传统 → 再分人名（一人一文件夹）→ 一人一个 Markdown 文件**
- 全部路径均为**仓库内相对路径**，文中不含任何本机绝对路径
- 每人文件内固定含两个维度：
  - **A 类 · 对自我的认知**（心性、自省、欲望、修养、生死、人格理想、自我价值）
  - **B 类 · 对外界的认知**（他人、社会、政治、自然、宇宙、知识、语言、因果、价值判断）
- 每人 ≥ 50 条。

## 1. 方法与真伪原则（重要，先读）

这一套语料是要拿去做统计的，**数据的可靠性决定结论的有效性**。因此定三条硬规矩：

**① 有出处才收录。**
每条语句必须指向具体文献（《论语·为政》、柏拉图《申辩篇》、尼采《善恶的彼岸》等）。凡常见但查无实据的「名人名言」，一律不收，或收进文末「存疑/伪托」栏并明确标注。

**② 转述型人物要注明来源性质。**
- 苏格拉底、释迦牟尼本人无著作，语录来自弟子记录（柏拉图、色诺芬 / 佛典结集）。这类文件的出处分两层标注：`《申辩篇》38a（柏拉图记述苏格拉底）`。
- 东西方语句存在译本差异，译文标注「参考译本」或标 `〔译〕`，表示措辞随译本而异、语义无争议。

**③ 归属存疑的经典名句单独隔离。**
例如「我思故我在」有确定出处（《谈谈方法》/《第一哲学沉思集》），但「存在即合理」是黑格尔「凡是合乎理性的都是现实的」的通俗化改写，**必须标注为改写**，不能当原句统计。

## 3. 派别与核心思想速查

**儒家**：以「仁」为核心，重人伦、礼制、修身与入世。孔子立「仁礼」骨架 → 孟子补「性善/仁政」→ 荀子转向「性恶/礼法」。宋明分为**理学**（程朱：性即理、格物穷理）与**心学**（陆王：心即理、致良知）两系。

**道家**：以「道」为根本，主张自然、无为、超越人为造作。老子重「反」与「柔」，庄子重「齐物」与「逍遥」，魏晋玄学（王弼贵无、郭象独化）把它推向本体论。

**墨家**：兼爱、非攻、尚贤、节用、非命。先秦「显学」，与儒家并为两大流派，后中绝。

**法家**：以人性自利为前提，主张法术势并用、以法为教、以吏为师。商鞅重「法」，申不害重「术」，韩非集大成。

**名家/阴阳家/兵家**：分别处理概念逻辑（白马非马）、宇宙图式（五德终始）、军事对抗（知彼知己）问题。

**中国佛学**：般若学（僧肇）→ 禅宗（慧能）为佛教中国化的两条主线，「不立文字、直指人心」。

**古希腊三大家**：苏格拉底把哲学从自然转向人（德性即知识）→ 柏拉图建立理念论 → 亚里士多德分科化、经验化。

**斯多亚**：区分「可控/不可控」，以理性顺自然，追求内在不动心。爱比克泰德、塞涅卡、奥勒留为罗马三代表。

**唯理论 vs 经验论**：笛卡尔/斯宾诺莎/莱布尼茨主张知识源于理性；洛克/休谟主张知识源于经验。康德以「先验」调和二者。

**德国古典**：康德（批判哲学）→ 费希特/谢林 → 黑格尔（辩证法与绝对精神），后分化为叔本华的悲观唯意志论与马克思的实践唯物论。

**存在主义一系**：克尔凯郭尔 → 尼采 → 海德格尔 → 萨特/加缪。「存在先于本质」「向死而生」「荒诞与反抗」。

**分析哲学**：弗雷格 → 罗素/维特根斯坦，把哲学问题还原为语言问题。

**佛教与中观**：缘起→无我→空。龙树以「八不」破一切执，立二谛。


三行标题（`## 二、`／`## 三、`／`## 四、`）**必须逐字一致且带（A类）（B类）**——`工具-统计校验.py` 靠它们定位并计数。

### 4.3 语录条目格式

**规范形态（v2）**：`1. 语句原文。——《文献·篇名》〔译〕⚠️ #self-other`

由四段构成，顺序固定：

| 段 | 内容 | 例 |
|---|---|---|
| ① 序号 | `N.` + 空格 | `1.` |
| ② 语句 + 句读 | 原文，以 `。？！…）」` 之一收尾 | `己所不欲，勿施于人。` |
| ③ 出处 | `——《文献·篇名》`，**紧贴**句读 | `——《论语·颜渊》` |
| ④ 标记区 | 放在出处**之后**，顺序 `〔译〕`／`〔意译〕` → `⚠️` → `#self-other` | `〔译〕⚠️` |

三条硬规则：

1. **句末标点必须紧贴 `——`**。允许 `。？！…）」` 收尾；**任何标记都不得插在 `。` 与 `——` 之间**。
2. **`——` 后必须直接是 `《`**。出处一律写作 `——《文献·篇名》`。
3. **标记统一放在出处之后**，顺序固定：`〔译〕`／`〔意译〕` → `⚠️` → `#self-other`，各以空格分隔，**不加反引号**（保证可机读）。

**第二种引用体例（合法变体）**：转述型人物须标出转述者时，写作 `——转述者《文献》`：

```
2. 未经省察的人生是不值得过的。——柏拉图《申辩篇》38a〔译〕
```

### 4.4 判定规则（**v2**，2026-09-21 修订）

> ⚠️ **本节是全文的关键前置条件。** v1 规则经审计确认**不可复现**：38.1% 的条目落在两可区，不确定带宽 **7.1 个百分点**——**大于本库任何统计效应**。规则不修，后面所有 A/B 比较都无意义。

#### 4.4.1 v1 规则的三个缺陷（审计结论）

| 缺陷 | 证据 |
|---|---|
| **两个独立标准被写成「或」** | v1 同时用了「句法主语」与「主题域」两个互相独立的标准。**320 条（占 A 类 15.0%）有自称词但主题偏 B**，被规则的两半同时认领 |
| **B 是杂类（catch-all）** | B 把「他人／社会／自然／宇宙／语言／知识」五个不同对象域塞成一类。而**认识论的主体本就是认知者自己**——笛卡尔「我思故我在」因此归哪边都不对 |
| **补丁无口径地位** | `#self-other` 用了 34 条，但 **A 类 16 条、B 类 18 条**——同一现象被拆到两边。同一个人（陆九渊）「宇宙便是吾心」标 A，「宇宙内事是己分内事」标 B |

**审计脚本**：`审查-判定规则.py`（可复跑）。实测：

- 含自称／自指词（我吾己予余自）的条目 **1578 条（35.0%）**
- 规则两半打架 **320 条（A 类的 15.0%）**
- 不确定区（同时含 A/B 两类线索）**1717 条（38.1%）**
- `#self-other` **34 条**，A 类 16 ／ B 类 18
- 含「心／性」却标 B 的 **354 条**（而 v1 明说 A 的主语可以是「心／性」）

| 对照项 | 量级 |
|---|---|
| **判定规则不确定带宽** | **7.1 pp** |
| 单样本标准误 SE | 6.7 pp |

#### 4.4.2 v2 规则：拆成两个正交字段，A/B 降级为派生量

**字段一 · 对象域（Object）**——这条语句**在谈论什么**

| 取值 | 判定 | 例 |
|---|---|---|
| `自我` | 关于「我是什么／我应当成为什么」的判断 | 「我思故我在」「仁义礼智我固有之」 |
| `他者` | 他人、人际、社会、政治 | 「己所不欲勿施于人」「法不阿贵」 |
| `世界` | 自然、宇宙、物 | 「天行有常」「宇宙即变化」 |
| `符号` | 语言、名、知识本身 | 「道可道非常道」「我的语言的界限…」 |
| `同一` | **我与世界的关系本身** | 「天地与我并生」「世界，是我的表象」 |

**字段二 · 陈述类型（Claim）**——这句**话在做什么**

`描述`（是什么）／`规范`（应当如何）／`方法`（如何做到）

**判定用「改写测试」，可复现**：把句子改写成「它回答了哪个问题？」

```
"我是什么／我应当成为什么"  → 自我
"他人／社会应当如何"        → 他者
"世界如何运作"              → 世界
"我们如何知道／如何言说"     → 符号
"我与世界是不是一回事"       → 同一
```

**以「谈论对象」为准，不以出现的字为准。** 三条校正示例：

| 句子 | v1 归属 | v2 归属 | 理由 |
|---|---|---|---|
| 「己所不欲，勿施于人」 | A（有「己」） | **他者** | 回答的是"他人应如何被对待" |
| 「吾尝终日而思矣，不如须臾之所学也」 | A（有「吾」） | **符号** | 回答的是"如何获得知识" |
| 「宇宙便是吾心，吾心即是宇宙」 | 两可 | **同一** | 回答的是"我与世界是不是一回事" |

**A/B 降级为派生聚合**（保留与旧数据的可比性）：

```
A · 对自我的认知 = 对象域 ∈ {自我}
B · 对外界的认知 = 对象域 ∈ {他者, 世界, 符号}
同一             = 对象域 ∈ {同一}      ← 单列，不并入 B
```

`#self-other` 由自由手打的补丁**升格为机读取值 `同一`**，位置固定在出处之前。

v2 规则需**重新标注全部 4505 条**方可生效。当前库仍是 v1 口径，因此：

1. 现有 A/B 数字**仍可用于探索**，但任何组间比较必须标注「v1 规则下」，且不得作为结论；
2. 重标时优先复核三类：**320 条冲突项 → 34 条 `同一` 项 → 354 条含「心／性」的 B 类项**；
3. 重标完成后重跑 `工具-统计校验.py` 与 `分析-多维模型.py`，替换全部数字。

## 6. 升维聚合哲学（十二条轴）

把 77 位思想家 / 4505 条语句**聚合到十二条互相独立的轴上**重看，再把十二条轴收敛为四个问题。这是本项目的**主要内容产物**。

| 产物 | 说明 |
|---|---|
| **`升维聚合哲学.md`** | 主文档：轴系设计 + 十二轴逐轴聚合 + 统合归总 |
| `元数据.csv` | 77 人的结构化标签：核心关切／文体／可靠度 |
| `升维分析报告.md` | 数据层面的分析（作为**数据可用性的限制说明**，不是主要内容） |
| `分析-多维模型.py` | 计算脚本，可复跑 |
| `分析结果.md` | 脚本原始输出 |

### 6.1 轴系：四组 × 三条 = 十二条

| 组 | 轴 | 这条轴在问什么 |
|---|---|---|
| **A · 本体轴**：世界以什么方式存在 | **A1 界线** | 自我在哪里结束，世界从哪里开始 |
| | **A2 关系** | 关系先于实体，还是实体先于关系 |
| | **A3 时间** | 存在物是恒常的，还是流变的 |
| **B · 结构轴**：认知如何组织 | **B1 纵深** | 自我分几层，杠杆在哪一层 |
| | **B2 信道** | 认知是编码与传输，必有损耗 |
| | **B3 边界** | 哪里够不到（生命／结构／伦理） |
| **C · 动力轴**：认知如何运转 | **C1 模态** | 事件是被决定的，还是条件依赖的 |
| | **C2 更新** | 先验设多厚，信念如何修正 |
| | **C3 涌现** | 秩序是设计出来的，还是自发产生的 |
| **D · 实践轴**：如何行动 | **D1 互动** | 共时：他人是对手还是伙伴 |
| | **D2 尺度** | 历时：什么被淘汰，什么活下来 |
| | **D3 干预** | 控制器放在法／心／理／自然 |

> 含**离散取值**（每条轴能取哪些值）的完整轴系表见 `升维聚合哲学.md` §1.3。

**轴系的取舍标准有三条**：① 互相独立（能举出真实人物证明四种组合都存在）；② 每条轴都有跨传统的语料支撑；③ 合起来能覆盖全部语句，无明显遗漏。

> **修订记录（v2）**：初版用八模型（系统／分层／约束／博弈／控制／概率／进化／贝叶斯），复核发现**四组重叠**——系统⊃控制论、系统⊃分层、概率⊃贝叶斯、博弈⊂进化；并**缺失四条轴**——关系/实体、恒常/流变、编码/信道、涌现/设计。v2 拆解重叠、补齐缺轴，形成现在的十二条。

### 6.2 十二条轴收敛为五个问题

| # | 问题 | 由哪些轴构成 |
|---|---|---|
| ① | 我在哪里结束，世界在哪里开始？ | 界线 + 关系 |
| ② | 哪一层不动？ | 时间 + 纵深 |
| ③ | 秩序和知识从哪里来？ | 信道 + 更新 + 涌现 |
| ④ | 我能改变什么，必须接受什么？ | 模态 + 互动 + 尺度 + 干预 |
| ⑤ | 我到哪里去？ | 目的（v3 新增） |

**①②⑤ 合起来就是「我是谁 · 我从哪里来 · 我到哪里去」；③④ 是三问接不住的「运作两问」**——它们问的是「怎么运转」，不是「在哪里」。详见 `升维聚合哲学.md` §附论。

这五个问题穷尽了「一个人必须表态的东西」——不回答本身就是一种回答（取默认值）。每位哲学家的全部主张，都可以表示为这五个问题的一组取值（对照表见 `升维聚合哲学.md` §3.2）。

### 6.3 归总

> **哲学史上看起来无穷无尽的分歧，是四个问题的取值差异。没有第五个问题。**
>
> 其中**第二个问题最关键**：你选哪一层作为不变的支点，决定了其余三个问题的答案。
> 不动点设在「天」→ 儒家；设在「法」→ 法家；设在「缘起」→ 佛家；设在「我思」→ 笛卡尔。

### 6.4 数据可用性限制（读语料时必看）

以下五条是**数据层面的限制**，不是分析结论，但会影响任何基于本语料库的量化推断：

1. **⚠️ 尺子本身不可信（最要紧的一条）**。把「自我／外界」当测量工具做信度检验（`信度检验.py`）：两名独立评分者对 3329 条重新分类，**κ = 0.150**——低于 0.20 的作废线。由此推出的**最小可检出差异 MDC = 16.9 pp**。这意味着**本库此前报告的全部组间差都沉在噪声里**：

   | 效应 | 量级 | 判定 |
   |---|---|---|
   | 传统组间差（中国 vs 西方） | 2.7 pp | ✗ 不可检出 |
   | 关切最大组间差（修养 vs 制度） | 5.8 pp | ✗ 不可检出 |
   | 判定规则不确定带宽 | 7.1 pp | ✗ 不可检出 |
   | **德谟克利特 vs 巴门尼德（自然实验）** | **32.0 pp** | **✓ 可检出** |

   **好消息**：换用 §4.4.2 的对象域规则后，评分者间信度 **κ = 0.864**（两名独立编码员盲编码 150 条，一致率 90.0%），**MDC 降至 6.8 pp**。尺子是可修的。

2. **⚠️ 全库 A 占比要修正：不是 47.3%**。三套互相独立的方法（对象域盲编码 40.3%、句法判据 35.0%、主题判据 36.6%）**都收敛到 36–40%**，而现标 47.3% 孤立在外——**现标系统性高估了约 8–11 pp**（v2 编码与现标的一致性 κ=0.644，A 率差 8.1 pp）。

3. **编纂配额截断**：51%（39/77）的 A 占比恰好 = 50.0%，纯二项随机期望仅 6.7 人（超出 5.8 倍）。数据生成过程实为 `观测A占比 = min(材料自指可及比例, 配额上限≈50%)`，即**右删失**——65 个 ≈50% 的样本观测值不携带独立信息，**有效样本是左尾 12 人而非 77 人**。

4. **方差归属**：可靠度 η²=31.2%、文体 η²=26.5%、核心关切 η²=26.3%，而**传统（中/西/印/伊斯兰波斯/日）仅 η²=6.5%**。差异主要来自传承结构，不是文化。

5. **自然实验**：德谟克利特（A=51.6%）vs 巴门尼德（A=19.6%）——同代、同传统、同为残篇，仅因伦理格言是否幸存而相差 32.0 pp。**「低 A 占比」记录的是幸存者偏差，不是思想取向。**

> 详细论证见 `升维分析报告.md`；信度检验的可复跑脚本为 `信度检验.py` 与 `编码一致性.py`，
> 盲编码原始数据为 `编码样本.csv`／`编码-甲.csv`／`编码-乙.csv`。
