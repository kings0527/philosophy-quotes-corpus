# 哲学统计 · 总览索引

## 0. 这个项目是什么

把古今中外哲学家、思想家的**有出处语句**摘录成结构化语料库，供后续做「哲学统计」——比如：统计各派别在「自我认知」与「外界认知」上的比重差异、不同时代的问题意识迁移、中西对比等。

- 目录：`D:\philosophy\哲学统计\`
- 组织方式：**先分地域/传统 → 再分人名（一人一文件夹）→ 一人一个 Markdown 文件**
- 每人文件内固定含两个维度：
  - **A 类 · 对自我的认知**（心性、自省、欲望、修养、生死、人格理想、自我价值）
  - **B 类 · 对外界的认知**（他人、社会、政治、自然、宇宙、知识、语言、因果、价值判断）
- 每人 ≥ 50 条。

## 1. 方法与真伪原则（重要，先读）

这一套语料是要拿去做统计的，**数据的可靠性决定结论的有效性**。因此定三条硬规矩：

**① 有出处才收录。**
每条语句必须指向具体文献（《论语·为政》、柏拉图《申辩篇》、尼采《善恶的彼岸》等）。凡常见但查无实据的「名人名言」，一律不收，或收进文末「存疑/伪托」栏并明确标注。

**② 转述型人物要注明来源性质。**
- 苏格拉底、释迦牟尼本人无著作，语录来自弟子记录（柏拉图、色诺芬 / 佛典结集）。这类文件的出处分两层标注：`《申辩篇》38a（柏拉图记述苏格拉底）`。
- 东西方语句存在译本差异，译文标注「参考译本」或标 `〔译〕`，表示措辞随译本而异、语义无争议。

**③ 归属存疑的经典名句单独隔离。**
例如「我思故我在」有确定出处（《谈谈方法》/《第一哲学沉思集》），但「存在即合理」是黑格尔「凡是合乎理性的都是现实的」的通俗化改写，**必须标注为改写**，不能当原句统计。

## 3. 派别与核心思想速查

**儒家**：以「仁」为核心，重人伦、礼制、修身与入世。孔子立「仁礼」骨架 → 孟子补「性善/仁政」→ 荀子转向「性恶/礼法」。宋明分为**理学**（程朱：性即理、格物穷理）与**心学**（陆王：心即理、致良知）两系。

**道家**：以「道」为根本，主张自然、无为、超越人为造作。老子重「反」与「柔」，庄子重「齐物」与「逍遥」，魏晋玄学（王弼贵无、郭象独化）把它推向本体论。

**墨家**：兼爱、非攻、尚贤、节用、非命。先秦「显学」，与儒家并为两大流派，后中绝。

**法家**：以人性自利为前提，主张法术势并用、以法为教、以吏为师。商鞅重「法」，申不害重「术」，韩非集大成。

**名家/阴阳家/兵家**：分别处理概念逻辑（白马非马）、宇宙图式（五德终始）、军事对抗（知彼知己）问题。

**中国佛学**：般若学（僧肇）→ 禅宗（慧能）为佛教中国化的两条主线，「不立文字、直指人心」。

**古希腊三大家**：苏格拉底把哲学从自然转向人（德性即知识）→ 柏拉图建立理念论 → 亚里士多德分科化、经验化。

**斯多亚**：区分「可控/不可控」，以理性顺自然，追求内在不动心。爱比克泰德、塞涅卡、奥勒留为罗马三代表。

**唯理论 vs 经验论**：笛卡尔/斯宾诺莎/莱布尼茨主张知识源于理性；洛克/休谟主张知识源于经验。康德以「先验」调和二者。

**德国古典**：康德（批判哲学）→ 费希特/谢林 → 黑格尔（辩证法与绝对精神），后分化为叔本华的悲观唯意志论与马克思的实践唯物论。

**存在主义一系**：克尔凯郭尔 → 尼采 → 海德格尔 → 萨特/加缪。「存在先于本质」「向死而生」「荒诞与反抗」。

**分析哲学**：弗雷格 → 罗素/维特根斯坦，把哲学问题还原为语言问题。

**佛教与中观**：缘起→无我→空。龙树以「八不」破一切执，立二谛。

## 4. 文件规范

### 4.1 目录结构

```
哲学统计/
├── README.md                     ← 本文件（总览索引）
├── 中国哲学/<人名>/<人名>.md
├── 西方哲学/<人名>/<人名>.md
├── 印度哲学/<人名>/<人名>.md
└── 伊斯兰与波斯/<人名>/<人名>.md
```

### 4.2 每份语录文件的固定结构

```markdown
--- YAML frontmatter：人物 / 生卒 / 地域 / 时代 / 派别 / 核心思想 / 主要文献 ---
# 人名
## 一、人物与思想概述
## 二、对自我的认知（A类）
## 三、对外界的认知（B类）
## 四、语录统计
## 五、出处与真伪说明
```

### 4.3 语录条目格式

```
1. 语句原文。——《文献·篇名》
```

- 每条**必须**带出处，用 `——《文献》` 收尾；
- 存疑、伪托、或通俗化改写的条目，用 `⚠️` 标记，并归入文末「说明」；
- 译文类标 `〔译〕`（措辞随译本而异）。

### 4.4 两维度的判定规则（保持一致，便于统计）

| 维度 | 判定标准 | 典型主题 |
|---|---|---|
| **A · 对自我的认知** | 主语为「我/吾/心/性」或指向自我修养、自我判断 | 自省、欲望、恐惧、生死、人格理想、自知之明、精神自由 |
| **B · 对外界的认知** | 指向我之外的他人、社会、自然、宇宙、语言、知识 | 政治、伦理关系、天道、自然规律、认识论、群体行为、是非标准 |

**边界处理**：「我」与「世界」同构的句子（如「天地与我并生」），计入 B 类并在条目后标 `#self-other`，供后续单独统计。

### 5.2 可复现的校验方式

`工具-统计校验.py` 做三件事，可随时重跑：

1. 按 `## 二、对自我的认知（A类）` / `## 三、对外界的认知（B类）` 定位章节，统计编号条目数；
2. 与 frontmatter 的「统计」声明比对，并检查每条语录是否含 `《》` 出处；

当前结果：**77 人 / A 2133 条 / B 2372 条 / 合计 4505 条 / 全库 A 占比 47.3%；标题规范、出处覆盖率、声明一致性 全部通过。**

附加口径统计：

| 口径 | A | B | 合计 | A 占比 |
|---|---|---|---|---|
| **全库（宽松口径，含 `⚠️`）** | 2133 | 2372 | **4505** | 47.3% |

### 5.3 初步统计信号（供参考，勿直接当结论）

1. **全库 A 占比 47.3%，略低于对称线。** 语录体文献整体更偏外向。
2. **两端极值说明了什么：**
   - A 最高：陆九渊 53%、爱比克泰德 53%、克尔凯郭尔 53%、叔本华 52%、德谟克利特 52%——几乎全是「修养—救赎」型思想。
   - A 最低：巴门尼德 20%、惠施 23%、公孙龙 26%、商鞅 30%、赫拉克利特 34%——全是「本体论／逻辑／制度」型思维，关注存在、名实、耕战，几乎不反省自我。
3. **跨传统对照组**：爱比克泰德（罗马·斯多亚）53% ≈ 陆九渊（南宋·心学）53%；叔本华 52% ≈ 德谟克利特 52%。**A 占比看起来与「是否以修养/救赎为核心关切」相关，而与时代、地域关系更弱。**
4. **中国内部的「内向—外向」轴清晰**：心学/理学一系偏高（陆九渊 53%、王阳明/朱熹/程颐/程颢 50%），法家、名家、兵家、墨家偏低（商鞅 30%、公孙龙 26%、墨子 37%）。
5. **⚠️ 最重要的方法论警告：大量文本恰好落在 50%。** 全库 77 人中有 40 人 A 占比正好 50%。这**更像是「语录体/格言体」这种文献体裁的产物**（编者为求体例整齐而均衡取条），而不一定是思想差异。**做统计前必须控制「文体」这个混杂变量**，否则会得到虚假的对称性。

用八个思维模型对全库做「升维」分析：**系统论 · 分层 · 约束 · 博弈论 · 控制论 · 概率论 · 进化论 · 贝叶斯**。

| 产物 | 说明 |
|---|---|

| `分析结果.md` | 脚本原始输出 |

### 6.1 核心结论（一句话）

**这份语料库目前测不出「思想家之间的自我—世界取向差异」——它测出来的是「文献传承结构」。**

### 6.2 三个决定性证据

1. **84%（65/77）的人 A 占比落在 ±1 个标准误（±6.7 pp）内**，与 50% 不可区分；经 Bonferroni 校正（临界 \|z\|>4.30）后，**全库 2926 对比较中没有任何一对差异显著**（最大 \|z\|=3.83）。
2. **51%（39/77）的人 A 占比恰好是 50.0%**，纯二项随机的期望只有 6.7 人——**超出 5.8 倍**，是编纂配额的指纹。
3. **解释 A 占比的是「传承结构」而非「文化」**：可靠度 η²=31.2%、文体 η²=26.5%、核心关切 η²=26.3%，而**传统（中西印伊日）只有 η²=6.5%**。

### 6.3 最漂亮的一组对照（自然实验）

| 人物 | A 占比 | 材料状况 |
|---|---|---|
| 巴门尼德 | **19.6%** | 仅存约 19 条残篇，**全部论「存在」** |
| **德谟克利特** | **51.6%** | 约 300 条残篇，其中**伦理学格言**经斯托拜乌斯《选集》大量保存 |

**同代、同传统、同为残篇**，仅因伦理材料是否幸存，A 占比相差 **32.0 个百分点**。→ 「低 A 占比」记录的是**幸存者偏差**，不是思想取向。

### 6.4 方法学修正（重要）

数据生成过程实际是：

```
观测 A 占比 = min( 材料中自指内容的可及比例 , 编纂配额上限 ≈ 50% )
```

这是一个**右删失模型**。含义：

- **65 个 A 占比 ≈ 50% 的人，观测值不携带独立信息**（被配额封顶遮住）
- **只有左侧 12 人（A<45%）近似等于真实可及比例**
- **有效样本量是 12 人，不是 77 人**

### 6.5 下一步的三个修正方案

- **A · 用删失模型替代均值比较**（最优先）：输出改为「12 个可识别估计 + 65 个区间下界」
- **B · 加独立于计数的控制论指标**：计算反馈词密度（省/自/反/克/悔… vs 法/令/制/度/禁…），不经过人工 A/B 归类，可给删失样本恢复信息
- **C · 用佚书目录构造生存分析样本**：以《汉书·艺文志》著录而亡佚者为「死亡样本」，才能真正检验博弈论假说
